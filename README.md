# Dumby 🧠

**Dumby** is a deliberately dumb AI chatbot for the web.  
It gives confidently incorrect answers, fake facts, and completely unnecessary confidence.

> “100% confident. 0% correct.”

## Features

- No server, API key, or installation required
- Works entirely in the browser
- Mobile-friendly chat interface
- Fake “thinking” animation
- Recognizes greetings, math, facts, identity, and goodbyes
- Fully offline
- Easy to customize

## Run it

1. Download or clone this repository.
2. Open `index.html` in any web browser.

That’s it.

```bash
git clone https://github.com/YOUR_USERNAME/dumby.git
cd dumby
open index.html
```
